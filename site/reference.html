Source map

PathWhat it does
cmd/serverMain access-vw binary: RBAC provider + virtual-workspace root apiserver
cmd/scar-to-kubeconfigCalls SCAR and writes a scoped kubeconfig
pkg/serverOptions and wiring: root apiserver, delegated authentication, per-VW authorization, debug endpoint
pkg/graphIn-memory permission graph and query layer
pkg/rbacproviderWatches RBAC state and translates grants into graph entries
pkg/virtual/scarAccess virtual workspace: create-only REST storage for SelfClusterAccessReview
pkg/virtual/mcpMCP virtual workspace: transport, scoping, impersonated per-workspace clients, kcp-native tool registration
config/apiexportAPIExport and APIResourceSchema for access.kcp.io
hack/kindFull-stack Kind automation, manifests, Helm values, and helper scripts
docs/Walkthroughs for local and Kind-based testing

CLI flags

FlagMeaning
--secure-portTLS serving port for access-vw, default 9443
--kubeconfigRequired path to the kubeconfig used for TokenReview and RBAC watching
--endpoint-baseFront-proxy URL prefix used when building cluster endpoints in SCAR responses
--apiexport-endpointsliceEnables multi-shard mode and watches workspaces bound to the named APIExportEndpointSlice
--requestheader-client-ca-fileCA bundle for verifying the front-proxy's client certificate before trusting X-Remote-* identity headers

Environment

LayerConfiguration detail
KeycloakRealm kcp, test users alice/bob, dynamic client registration enabled, audience mapping for kcp
Envoy AI GatewayHandles HTTPS, OAuth, MCP routing, and bearer-token forwarding to the backend
kcpFrontProxy validates OIDC tokens, exposes logical cluster endpoints, and provides TokenReview for access-vw
access-vwRuns a TLS root apiserver on :9443 serving both virtual workspaces backed by the same graph

API details

PathPurpose
POST /mcpExternal AI Gateway entrypoint used by MCP clients in the Kind stack
POST /services/mcpInternal access-vw MCP backend path behind the gateway (streamable HTTP)
POST /services/access/apis/access.kcp.io/v1alpha1/selfclusteraccessreviewsSCAR workspace discovery endpoint
GET /debug/graphPretty-printed graph snapshot for debugging; HTTPS, requires an authenticated user
GET /healthzReadiness probe; returns ok when the graph is ready
