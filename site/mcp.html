Naming convention

kcp-specific objects use <verb>_kcp_<noun>. Generic Kubernetes objects use <verb>_<noun>. That keeps the tool list readable while clearly separating kcp-native inventory from generic cluster operations.

Per-user scoping

Each MCP session gets a tool surface derived from the caller's SCAR result. The user sees only the workspaces they are authorized for, and every tool call is constrained to that per-user workspace set.
